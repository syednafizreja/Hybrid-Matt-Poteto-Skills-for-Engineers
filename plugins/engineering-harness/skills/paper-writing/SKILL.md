# Paper writing

Use this for a Q1 or Q2 mechanics manuscript, a section, or a response to reviewers.

## Structure

1. The title names the system and the result.
2. The abstract contains the question, the method, one quantitative result with a unit, and one limit.
3. Use this order: introduction, method, verification, results, limits, conclusion.
4. A short Q2 paper keeps that order and drops nothing the main claim depends on.

## Claims

1. Pair each claim with the figure, table, or test that supports it.
2. Put the modeling limit in the same paragraph as the claim.
3. Copy numbers from result files. If the file and the sentence disagree, stop and fix the sentence.
4. Open `references/ai-writing-tells-and-humanization.md` before a draft is finished.

## LaTeX

1. Build with Tectonic when the repo has a Tectonic config. Otherwise use the repo's latex command.
2. Cite only entries in the repo bibliography. Do not invent a DOI, page, author, or number.
3. Done when the PDF builds and each result number matches a file.

## Response to reviewers

1. One reviewer comment per block.
2. Order inside the block: the comment, the change, the new evidence (file, figure, or equation).
3. If you disagree, say what evidence supports keeping the original claim.
