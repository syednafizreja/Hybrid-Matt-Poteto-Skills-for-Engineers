# Research flow

Use this for a literature question, a modeling choice, or a spec. Absorbed triggers: grill, grill-with-docs, brainstorm, to-spec, wayfinder, research.

## Frame

1. Write the question as a quantity, a system, and the decision the result changes.
2. Name the unit, the boundary conditions, and the comparison case. Stop the interview when those three are explicit.
3. List the assumption that would make the answer useless.

## Sources

1. Read the repo result files and the project bibliography before the web.
2. Prefer the paper, solver manual, code, or standard that owns the claim.
3. Put the source next to the claim. If a paywall blocks the official text, record the free official document you used instead.

## Spec

1. Write the acceptance check: command, tolerance, unit, and output file.
2. Split a job that does not fit one session. Each slice ends in a command that can fail.

## Note

1. Write one markdown note in the repo folder that already holds notes.
2. Every number has a unit and a source.
3. Done when a reader can rerun the check from the note without this chat.
